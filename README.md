# OldMoney Fashion Store

A PHP-based fashion e-commerce website for showcasing and selling stylish products online.

## Features
- Product browsing
- Shopping cart
- Checkout flow
- Admin dashboard for managing products, users, contacts, and feedback

## Tech Stack
- PHP
- MySQL
- HTML / CSS / JavaScript
- XAMPP

## Project Setup
1. Place this project inside your XAMPP `htdocs` folder.
2. Import `oldmoney_fashion.sql` into your MySQL database.
3. Update your database settings in `db.php` if needed.
4. Start Apache and MySQL in XAMPP.
5. Open the project in your browser.

## Folder Structure
- `admin_*` files for admin features
- `assets/` for images and styles
- `uploads/` for uploaded files
- `oldmoney_fashion.sql` for database setup
